# Mugsun 全站验收评分手册

> **版本**：v1.0 · **建立日**：2026-08-26  
> **目标**：对 mugsun 全部功能页进行专业、可复现的浏览器端到端验收；**每页满分 100，仅当零缺陷时方可标记 100**。  
> **环境基线**：`mugsun-boot :8080` · `mugsun-pc :3006` · PostgreSQL `mugsun` · Redis · 账号 `admin/123456`（dev 可设 `mugsun.captcha.enabled=false` 跳过行为验证码）

## 1. 评分总则

### 1.1 满分定义（100 分）

同时满足以下全部条件，方可给 **100**：

| 维度 | 权重 | 100 分判据 |
| --- | --- | --- |
| **功能正确性** | 35% | 主流程 + 边界 + 错误分支均符合需求；网络请求命中后端；写操作落库可反证 |
| **交互与可达性** | 25% | 无反人类操作；控件状态不弹回；矮视口（1366×620）与标准视口（1920×817）内容全可达 |
| **UI 与视觉** | 20% | 无多余滚动条；无裁切/半截字；明暗主题可读；对齐/间距/文案无歧义 |
| **反馈与健壮性** | 10% | 加载/空/错三态完整；危险操作二次确认；提交防重复；失败有明确提示 |
| **安全与权限** | 10% | 未登录 401；低权写 403；租户不串数；敏感字段脱敏（按页涉及项） |

**扣分规则**：任一维度存在 1 个 P0（阻断/数据错误/不可达）→ 该页最高 **60**；存在 P1（体验严重/易误操作）→ 最高 **85**；仅 P2（文案/微对齐）→ 最高 **95**。修复后须**同视口复验**再上调分数。

### 1.2 缺陷分级

| 级别 | 定义 | 示例 |
| --- | --- | --- |
| **P0** | 功能不可用、数据错误、安全洞、内容不可达 | 登录失败、保存未落库、按钮被裁切点不到 |
| **P1** | 可用但体验差、易误导、性能明显卡顿 | 多余滚动条、控件空转、无 loading、危险操作无确认 |
| **P2** | 轻微视觉/文案问题 | 列宽略紧、英文漏翻、tooltip 缺失 |

### 1.3 验收视口

- **标准**：1920×817（常见笔记本全屏减任务栏）
- **矮视口**：1366×620（小屏/分屏必测）
- **暗色**：抽验关键页切换 dark 主题

### 1.4 证据要求

每页记录：截图路径 / Network 关键请求 / psql 或 Redis 反证（写操作）/ console.error 为零。
