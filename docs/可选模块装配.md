# 可选模块装配说明

GIS 与埋点不是核心能力。源码已物理拆成独立积木；**不要的模块可以不引入依赖，或直接删掉对应目录**。长期 lite 分支不维护。

## 后端（mugsun-boot）

Maven 多模块：

| 模块 | 内容 |
| --- | --- |
| `mugsun-boot-core` | 认证、系统、流程、租户等核心（**无** gis/track/ai 源码） |
| `mugsun-boot-gis` | 地理信息（JTS、地图 API、菜单过滤状态） |
| `mugsun-boot-track` | 埋点分析（独立库迁移、采集/看板 API） |
| `mugsun-boot-ai` | AI 可选模块（模型/对话/知识库/编排等，见 `AI-PLAN.md`） |
| `mugsun-boot-server` | 装配壳；默认 **full** = core + gis + track + ai。单模块：`-Pgis-only,'!full'`、`-Ptrack-only,'!full'`、`-Pai-only,'!full'` |

### 全量（默认，与历史行为一致）

```bash
cd mugsun-boot
mvn -pl mugsun-boot-server -am package -DskipTests
# 产物：mugsun-boot-server/target/mugsun-boot.jar
java -jar mugsun-boot-server/target/mugsun-boot.jar
```

### 仅核心（不要 GIS / 埋点 / AI 代码与依赖）

```bash
# 关掉默认 full profile，只编 core + server（建议 clean，避免旧 fat jar 残留）
mvn -pl mugsun-boot-server -am clean package -DskipTests -Pbasic,'!full'
```

或在 `mugsun-boot-server/pom.xml` 中删除对 `mugsun-boot-gis` / `mugsun-boot-track` / `mugsun-boot-ai` 的依赖（以及 parent 里对应 module，若你 fork 后永不需要）。

core-only 时：

- 不需要 `mugsun_track` 库、不必装 PostGIS / pgvector
- 菜单自动隐藏 `/gis`、`/track`、`/ai`（`GisModuleStatus` / `TrackModuleStatus` / `AiModuleStatus` 缺省关闭）
- 登录 `/auth/info` 返回 `gisEnabled=false`、`trackEnabled=false`、`aiEnabled=false`

运行时临时关闭（jar 仍在 classpath）：

```bash
export MUGSUN_GIS_ENABLED=false
export MUGSUN_TRACK_ENABLED=false
export MUGSUN_AI_ENABLED=false
```

## 前端（mugsun-pc）

可选源码目录：

| 目录 | 说明 |
| --- | --- |
| `modules/gis` | 地图页、OpenLayers/Cesium 封装、`gisPick` |
| `modules/track` | 埋点看板、SDK 插件 |

构建期开关（`.env`）：

```bash
VITE_ENABLE_GIS=true    # false = 不注册 GIS 路由 / gisPick
VITE_ENABLE_TRACK=true  # false = 不挂载埋点 SDK
VITE_ENABLE_AI=true     # false = 不注册 AI 路由
```

彻底不要源码：删除对应 `modules/*` 目录，并去掉 [`src/router/modules/index.ts`](../../mugsun-pc/src/router/modules/index.ts) 里对该模块的 import；同时可从 `package.json` 移除 `cesium` / `ol` / `@mugsun/track-web` / `rrweb-player` 等依赖。

## 四种常见组合

| 组合 | 后端 | 前端 |
| --- | --- | --- |
| 全量 | 默认 full | 默认双开 |
| 只要基础 | `-Pbasic,'!full'` | `VITE_ENABLE_GIS=false` + `VITE_ENABLE_TRACK=false`（或删 modules） |
| 只要 GIS | `-Pgis-only,'!full'` | `VITE_ENABLE_GIS=true`，`VITE_ENABLE_TRACK=false`，`VITE_ENABLE_AI=false` |
| 只要埋点 | `-Ptrack-only,'!full'` | `VITE_ENABLE_TRACK=true`，其余两个 false |
| 只要 AI | `-Pai-only,'!full'` | `VITE_ENABLE_AI=true`，其余两个 false |
