验证码背景图
============

行为验证码的背景图放在这个目录里。
仓库里带了 12 张，文件名是 bg-01.jpg 到 bg-12.jpg。

要求
----

- 格式：jpg 或 png。
- 尺寸：建议 640×360，比例 16:9。
- 大小：每张不超过 200 KB。
- 来源：每张图的来源和许可，都要记到上一级目录的 SOURCES.md 里。
- 不能使用 tianai-captcha 自带的图片。

目录为空时
----------

目录里没有图片时，验证码使用纯色的占位背景。

生产环境请换成自己的图库
------------------------

仓库里的图是公开的，攻击者可以提前拿到它们，预先算好答案。
生产环境请换成不公开的图库。

把图片放到服务器的一个目录里，再修改配置：

    mugsun:
      captcha:
        background:
          dir: file:/opt/mugsun/captcha-bg/

默认值是 classpath:captcha/bg/，也就是这个目录。

目录默认每 600 秒重新扫描一次，换图不需要重启应用。
